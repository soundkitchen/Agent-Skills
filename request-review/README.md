# request-review

[you-are-a-reviewer](../you-are-a-reviewer/README.md) を起動したレビュアーのセッションに、今のブランチの PR のレビューを依頼する skill。結果を受け取ったら報告する。LGTM が出るまで、指摘の修正と再依頼を繰り返すこともできる。

## 前提

- Claude Code のセッション間メッセージ(`SendMessage` / `ListAgents`)が使えること
- 同じマシン上で、`you-are-a-reviewer` を起動したレビュアーのセッションが動いていること
- [GitHub CLI](https://cli.github.com/)(`gh`)がインストール・認証済みであること
- 今のブランチに、開いている PR があること。変更はすべてコミット・push 済みであること(足りない場合は、commit・push・PR 作成をするか確認される)

## 使い方

```
/request-review
/request-review skill-reviewer high --lgtm
```

「skill-reviewer にレビューを頼んで」「LGTM が出るまでレビューしてもらって」のような依頼でも起動する。ただし「レビューして」(Claude 自身にレビューさせる依頼)は `code-review` の役目で、この skill は起動しない。

## 引数

順番は自由。

| 引数 | 意味 |
|---|---|
| レビュアー名 | 依頼先のセッション名。省略すると、このセッションで前回依頼した相手。見つからない、または同じ名前が複数ある場合は確認される |
| `low` / `medium` / `high` / `xhigh` / `max` | 今回の依頼で使う code-review のレベル。省略するとレビュアーの既定を使う |
| `--lgtm` | LGTM が出るまで、指摘の修正と再依頼を繰り返す |
| その他の `--` で始まるフラグ | `--comment` など。依頼文にそのまま含め、レビュアー側で使われる(レビュアーが非対応のものは外される) |

`ultra` はレビュアーが非対応なので、指定すると別のレベルを聞かれる。

## 主な挙動

- **`--lgtm` なし:** 結果をまとめて報告し、指示を待つ。自分からは直さない。そのあと「LGTM まで続けて」と言えば、そこからラリーに切り替わる
- **`--lgtm` あり:** 指摘の修正・コミット・PR のブランチへの push・PR 本文の更新・インラインコメントへの返信までは、確認なしで進めて再依頼する。次の場合はユーザーに確認する
  - 修正に設計判断が要る
  - 以前決めた方針や、プロジェクトの docs・仕様から外れる
  - 指摘に同意できない
  - 新しい指摘が出続けて、ラリーが収束しない
- **再依頼には、** 前回の指摘、前回レビューされたコミット、各指摘への対応(直さないと決めたものはその理由)を含める。レビュアーを起動し直していても、前回の指摘に絞った再レビューになる
- **LGTM が出ても、マージはしない。** マージはユーザーが決める
- **このセッションで PR をマージしたら、** レビュアーにマージしたことを通知する(GitHub の画面や別のセッションでマージした場合は通知されない)
- **レビュアーへの依頼・通知と、ユーザーへの報告は、必ず指定された言語で書く。** 言語は、ユーザーの設定や指示(`language` 設定・CLAUDE.md・プロジェクトのルールなど)で指定されたものを使い、指定がなければユーザーが書いている言語に合わせる

挙動の詳細は [SKILL.md](SKILL.md) を参照。

## レビューの流れ(you-are-a-reviewer と組み合わせる)

1. レビュー担当用のセッションを `claude -n skill-reviewer` のように名前を付けて立ち上げ、`/you-are-a-reviewer medium --comment` で起動する
2. 作業中のセッションで PR を作り、「skill-reviewer にレビューを頼んで」と頼む(LGTM まで任せるなら「LGTM が出るまで」と添える)
3. レビュアーが code-review でレビューし、結果を返す(`--comment` なら PR にもインラインコメントが付く)
4. 指摘があれば直して再依頼する。再レビューは、前回の指摘に絞って確認される
5. LGTM が出たら、ユーザーがマージを指示する。マージすると、レビュアーにマージの通知が届く
